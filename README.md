Inventory Management System

📌 Project Overview

The Inventory Management System is a web-based application designed to help manage and track inventory efficiently. It provides features for adding, updating, viewing, and managing product information in one centralized system.

The project was developed as a college project to understand the implementation of a database-driven web application and basic inventory management workflows.

✨ Features

- Add new products to the inventory
- View available products
- Update product details
- Delete products from the inventory
- Track product quantity and availability
- Manage product information in a centralized database
- Simple and user-friendly interface
- Database integration for storing inventory records
